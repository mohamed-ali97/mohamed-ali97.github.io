# Portfolio source (React 19, Vite 8, Tailwind CSS 4, GSAP 3, Three.js)
Build steps:
1. python3 decode-assets.py   (restores public/img from public/img-assets.b64.txt)
2. npm install
3. npm run dev (local) or npm run build (dist/)
The live site at the repo root is the built output with the poster images inlined.
