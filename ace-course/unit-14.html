ملخص الكورس ومصادر تعلم تانية

Course summary, badge, and other learning resources

ده Unit الختام. مفيهوش تقنية جديدة: بيلخص أهداف الكورس، وبيشرح الـ badge والـ certifications، وبيدي موارد تكمل بيها. الوقت المقدّر حسب الكتاب: 00:30.

صفحات الكتاب: PDF صفحات 739-749

  • وصف أهداف الكورس وإيه اللي اتعلمته
  • الحصول على badge للكورس
  • التعرف على IBM Professional Certifications المتعلقة بالكورس
  • معرفة الموارد اللي تساعدك تتعلم أكتر

أهداف الكورس (Course objectives)

دي الأهداف اللي المفروض تكون حققتها بعد الـ 13 unit اللي فاتوا، بنص الكتاب:

  • Describe the features and uses of IBM App Connect Enterprise: تصف مميزات واستخدامات ACE
  • Develop, deploy, and test message flow applications: تطور وتنشر وتختبر message flow applications
  • Generate message flow applications from predefined patterns: تولد applications من patterns جاهزة
  • Use IBM App Connect Enterprise problem determination aids to diagnose and solve development and runtime errors: تستخدم أدوات تشخيص المشاكل لحل أخطاء التطوير والتشغيل
  • Describe the function and appropriate use of IBM App Connect Enterprise processing nodes: تصف وظيفة وطريقة الاستخدام المناسبة للـ processing nodes
  • Write basic Extended Structured Query Language and Java programs to transform data: تكتب برامج ESQL وJava أساسية لتحويل البيانات
  • Use the IBM Graphical Data Mapping editor to transform data: تستخدم الـ Graphical Data Mapping editor للتحويل
  • Define, use, and test simple XML and Data Format Description Language (DFDL) data models: تعرّف وتستخدم وتختبر نماذج بيانات XML وDFDL بسيطة
  • Describe supported transport protocols and how to call them in message flows: تصف الـ transport protocols المدعومة وإزاي تناديها في الـ flows

IBM badge

  • تحصل على Skills badge للكورس بالنجاح في quiz
  • الـ PDF بيدي لينكات (من developerworks) لطريقة الحصول على الـ badge وبادجات IBM Cloud تانية

الروابط دي في الـ PDF قديمة من 2020 (developerworks)، فتحقق منها قبل ما تعتمد عليها.

IBM Professional Certifications

  • بتحقيق شهادة IBM Professional Certification بتثبت إتقانك لمنتج IBM Cloud لصاحب العمل أو العملاء
  • الشهادات مستوى credential أعلى من الـ Skills badge لكورس واحد
  • شهادات المنتجات بتثبت معرفة قوية بالمنتج وغالبًا بتحتاج شهور شغل مع المنتج
  • متاحة لأدوار منها المطورين والـ administrators والـ business analysts
  • للتفاصيل: http://www.ibm.com/certify
